Read a wallet. Move nothing.

A viewing pass opens one wallet's private balance and history for reading: the view an accountant needs. It holds no key that signs, so nothing can be sent, unshielded or traded from this page. The pass is opened in this browser and kept only while the page is open.

Or .

What you will see

The wallet's private holdings, its private history with tokens and amounts, and a statement you can download as a file. The same things its owner sees.

What stays with you

The pass is not stored by this page and never sent to this site's server. Closing the tab closes the view. Nobody is told that you opened it.

Is it your own wallet?

Then use the wallet page. A pass is made there, on the Keys tab.
