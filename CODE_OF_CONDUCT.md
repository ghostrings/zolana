# Code of conduct

Contributors, reviewers and maintainers are expected to communicate respectfully, stay focused on technical evidence, acknowledge uncertainty and avoid harassment, personal attacks, discrimination, impersonation and publication of another person's private information. Do not request production keys, wallet exports or private customer data in public discussion. Respect upstream maintainers' time and contribution policies; do not create duplicate or promotional issues and pull requests.

Report abusive conduct privately to the project operator through an independently verified contact on [privacycash.fun](https://privacycash.fun), or use GitHub's reporting tools where appropriate. Report security issues according to [SECURITY.md](SECURITY.md), not in a public issue. Maintainers may moderate discussions or restrict participation in accordance with GitHub's rules. This document does not establish a formal security or legal response SLA.
