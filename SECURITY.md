# Security and responsible disclosure

GHOST Markets and privacycash.fun are independent projects. V27 is the historical locked release; the operator reported V33 upgraded, initialized and active. V39 permits owner-authorized, unaudited public market trading against the exact V33 deployment. Neither reproducible build verification nor local tests constitute an audit. Independent security review is not asserted. Do not test against live customer funds or make claims of private native settlement.

Report vulnerabilities privately through the [repository security page](https://github.com/ghostrings/zolana/security) if private vulnerability reporting is enabled, or request a secure reporting channel via the independently verified [project website](https://privacycash.fun). Never publish exploit details, seed phrases, private keys, wallet exports, private RPC credentials or personal financial information in public issues. Provide affected release, impact, and a sanitized reproduction. No bounty or response deadline is promised.

Keep production signing keys outside the source tree. The upgrade authority can replace the program's checks, including its liquidity-lock policy. A verified binary is not proof of immutability, regulatory compliance, security, or private settlement. Independent security and economic review remain recommended before accepting real assets. The source-controlled owner decision can disable the website path, but it does not pause the on-chain program. In an incident, the configured on-chain pauser can block buys/new launches; exits and eligible fee operations remain subject to the program rules.
